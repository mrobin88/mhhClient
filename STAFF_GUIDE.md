# Staff Guide Publication

The maintained staff guide is inside the authenticated staff workspace. After signing
in, select **Guide** in the header.

That guide covers day-to-day workflows, internal links, support contacts, access
requests, classes/JRTs, document outreach, and operational troubleshooting.

This repository is public, so production URLs, login details, PIN behavior, client
information, and internal support contacts are intentionally not duplicated here.
Developers should use [`README.md`](README.md) for the sanitized product and workflow
overview.
